# Item icons needed

## FOR ARCHER

Nothing: every item has a model, an image or a UI-drawn icon (`src/ui/ItemIconArt.luau`).

Generated by `lune run tests/ui/gen-item-icons-doc` from `src/ui/ItemIcons.luau` (do not edit by hand).

These items have no 3D model in the repo, so the UI draws a gradient placeholder tile with a glyph
(`src/ui/ItemIconView.luau`). Render each as a **512x512 PNG on a transparent background**, in the
current low-poly model style (chunky shapes, flat colours, soft top-left light, thin dark outline,
the item centred and filling about 80% of the frame, 3/4 view unless noted). Keep the subject
readable at 36 px.

**Where to paste the image id once uploaded:** `ItemIcons.IMAGES` in `src/ui/ItemIcons.luau`,
one line per item: `Upgrade_Luck = 123456789,` (the number of the uploaded Image asset). An image
replaces the placeholder tile; nothing else changes. Then regenerate this file.

Items that already render a real 3D model (mutations, plot skins) are not listed.
