Steal a Slime · proposal

Goo Gauntlet: a sky obby that changes every run

Clear a short parkour course floating above the map and your slimes earn 1.5× cash for 5 minutes. Then a 5-minute cooldown. By the time you can run it again, the course has rebuilt itself from a new set of sections with a new twist.

1.5×income for 5:00
5:00cooldown after the boost ends
~1 mingoal for a full run: keep it short
24 × 3sections, each with 3 layouts

The loop

A full cycle is 10 minutes: 5 boosted, 5 cooling down. The course rotates on the same 10-minute clock, so every run a player makes is on a course they haven't seen in that form.

  • Stacks by multiplying, like every other bonus. It becomes one more factor (obbyBonus) in Perks.bonusMultiplier, next to MVP, Blessed and the weekend boost.
  • Survives a rejoin. Save the boost end time and the "ready at" time in the player's data, the way the code boost saves boostUntil. Otherwise leaving and rejoining would skip the cooldown.
  • Your base stays open. While you're up in the sky, your slimes can still be stolen. A run takes about a minute, so it's a real choice: go now, or wait until the server is quiet.
  • Short on purpose. The goal is a run of about a minute at most. That's a guide, not a hard limit, but it means we never make the course longer to feel bigger. Variety comes from new sections, not more of them. Sections are kept short (see the section pool).
  • Falling isn't dying. You respawn at the last checkpoint (one after each section), so a fall costs a few seconds, not the run. No lives, no time limit. Kids on phones must be able to finish.
  • Your run timer counts anyway. Every finish shows your time and your best on this course, and the fastest time on the server goes on a board at the portal.

Rotating course

Each course is built from 5 sections in a fixed difficulty order (easy, easy, medium, medium, hard), plus one modifier. The pick comes from a seeded random number keyed to the 10-minute time slot, so every server builds the same course at the same time and players can talk about it. We already do this for the Exclusive shop rotation.

How each run stays unique

Players remember sections, not combinations, so a big pool alone isn't enough. Three layers of variety work together:

  • New sections every run. With 8 sections per tier and the no-repeat rule, each slot picks from at least 6 sections you didn't see last run. You'll see the same section again maybe once every 4 runs, never twice in a row.
  • Every section has 3 layouts. The same seed that picks the section also picks its layout: where the gaps are, how many platforms, which way the spinner turns, how fast the goo rises. Spinner A and Spinner C feel like different obstacles.
  • A modifier and mirror on top. A twist like Low Gravity or Night Run, or the whole course flipped, makes even a familiar section play differently.

Together that's over 25,000 section orders before layouts, modifiers and mirror. If analytics show players still getting bored, we add sections each update rather than making courses longer. Each section is a single module, so adding one is cheap.

  • The floor never vanishes. The sky has two course lanes. The new course builds in the empty lane. The old lane stays until its last runner finishes or 3 minutes pass, then clears.
  • Mirror is free variety. Sections are built in code from parts, so any section can be flipped left-to-right. That doubles how many layouts players see.

Section pool

Every section is about 30 studs long, has an entry pad and an exit pad at fixed heights, and ends on a checkpoint. All of them use the slime look: jelly, goo, bubbles.

Where it lives

The ground has little room: plots sit on a ring at radius 140 and the free yards between them are only about 85 studs deep. So the course floats in the sky, and the ground only needs a portal.

  • The portal shows your status: "Ready", "Boost 3:12" or "Ready in 1:40", plus "New course in 6:05". A world label, so it follows the label guide (phone read distance, explicit MaxDistance, a row in the registry).
  • The course is visible from the ground. A goo trail in the sky makes people ask what it is. That's free advertising for the feature.
  • Exact yard and height are Archer's call (WorldLayout and PropClearance). Bearing 337.5 is my suggestion because it balances the Hall of Fame on the other side.

Stopping cheaters

  • A finish counts only if the server saw every checkpoint in order, each within range of the player's position.
  • A minimum time per section (about a third of a normal run), so teleport or fly finishes fail.
  • The existing MovementGuard from the shared library watches players on the course. The finish touch is rate-limited.

Shared code

The rotation picker and the checkpoint validator have nothing slime-specific in them. They go to shared/luau (pure core, Lune specs) so Speed Escape and future games can use them.

Testing

  • Lune specs for rotation, boost rules and the finish check.
  • Hidden-Studio playtest: run the course with execute_luau (move the character from checkpoint to checkpoint), check the boost lands, the cooldown blocks a second finish, and a rejoin keeps both timers.
  • Screenshot every section and every modifier, at phone size too.

Decided

The cooldown starts when the boost ends

5 minutes boosted, then 5 minutes cooldown. Starting it at the finish would let players keep 1.5× running nonstop.

Your base can still be stolen while you're on the course

That makes going a real choice and keeps the obby from becoming a hiding spot. Players can't steal or carry slimes on the course.

The course rotates every 10 minutes

That matches the boost cycle, so every run is on a new course.

No Robux at launch

No skips or shorter cooldowns, so the boost doesn't feel pay-to-win. A cosmetic trail for fast times could come later.

Short runs, many sections

A run is about a minute at most. That's a goal, not a hard rule, but we never lengthen the course. We add variety with new sections and layouts.
