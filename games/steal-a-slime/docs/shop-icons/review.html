Steal a Slime: Roblox store icons

8 Game Passes and 125 Developer Products. These replace the two placeholder pictures every pass and product uses today, in Roblox's purchase popup, the Store tab on the game page and the Roblox Shop. Nothing is uploaded yet.

Picked: style B, Plum stage (Merijn, 2026-11-05). A and C stay below for reference.
Any icon to redo: name its key (the code under it).

1. Style options (on the 8 passes)

Roblox crops pass icons to a circle, so they are shown round here. The bottom rows are the same icons at 48 px on a light and a dark page.

A: Clean cut-out

Transparent background, like the in-game icons. Roblox puts it on its own grey or white.

B: Plum stage

Full-bleed lilac backdrop with a soft glow: the colour of the Exclusive Shop's preview stage.

C: Gold medal

A round gold-rimmed medal with a dark goo-teal face. Same shape whether Roblox shows it square or round.
