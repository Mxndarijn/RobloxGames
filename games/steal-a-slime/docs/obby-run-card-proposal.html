Steal a Slime · proposal for Merijn · 2 Nov 2026

Your ask: show the base lock timer on screen, make "Section x/8" fancier, 6 sections, show your furthest section (a fall does not take it away), and say the lock runs 50% slower in the obby.

Pick one: A, B or C. A is built in the branch so you can try it in Studio now; swapping to B or C is a small change. Colours are the real GooPalette ones: mint = progress, amber = timers, Ink wells for facts. No glow (the style guide bans glows on screen UI), so "furthest" is a mint ring, not a glow.

What every option shows

PartShows

LockYour base lock's time left, in amber, with a note that it runs slower. It counts down smoothly at half speed on screen. No lock running: "🔓 Base open".

Wording for the "slower" note

Player-facing, so your call. Any of these drops into any option.

OptionChipNotes
1 (built)50% slowerClosest to your "50% delay"; the number comes from Config.OBBY.LOCK_RATE.

No lock running shows 🔓 Base open (alternative: Unlocked).

Left out on purpose

Tier colours (easy / medium / hard) on the pips: every GooPalette colour already has a job (amber = timers, pink = losing something), so colouring tiers would blur those. The section's name is left out too: fewer words, and the picture banners in the course already name it.
