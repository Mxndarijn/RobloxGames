# 28. Inventory hotbar and panel (S3, client only, 2026-10-18)

**Status:** client-only. No new State field, remote, attribute or server code; the server stays the only owner of what is held.

- **Replaces** Roblox's backpack bar (`StarterGui:SetCoreGuiEnabled(Backpack, false)`, retried until the core scripts register).
- **List** (`src/ui/InventoryCore`, pure): the Bat first (the Tool every player gets, `BatTool`), then any other Tool in the Backpack / character by name (the Speed Coil while it is a Tool), then every owned PvP item (`State.pvp.owned`) in `Config.PVP_TOOLS` order. Permanent upgrades, the Lock, the Mystery Egg and consumables are never listed (consumables apply on purchase; the server holds no stock). Pictures come from the ItemIcons registry (`Pvp_<id>` through `ItemIcons.shopIconId`, a Tool by its own id, the Bat through `ItemIcons.HELD_TOOLS`); an unknown Tool gets the neutral tile.
- **Equip / use:** selecting a Tool equips or unequips it through the Humanoid (what the default backpack did); selecting a PvP item sends the existing `Request("EquipPvpItem", id?)` (no id = put away). One hand: selecting a Tool puts an equipped PvP item away first, selecting a PvP item unequips the Tools. `UsePvpItem` is not called (open question).
- **Hotbar:** bottom-centre zone `Layout.screen(...).hotbar` (between the money and status clusters, above them on a narrow portrait phone, hugging the bottom edge on a short landscape phone), at most 9 item slots plus the bag cell (`InventoryLayout`). Number keys 1-9 on keyboards, tap on touch (slot at least `Layout.MIN_TOUCH_DESIGN`), selected slot highlighted, name on hover or after a 0.4 s long press, cooldown seconds from `State.pvp.cooldowns`, stack count only if the server ever supplies one. Hidden while carrying (the server unequips tools then; the carry cards may use its place) and while a menu card is open. Items that do not fit a narrow phone's bar are in the panel.
- **Panel:** the bag cell opens the `Inventory` card (`Layout.MENU_HEIGHTS.Inventory`, same `Widgets.panel` chrome and `Layout.panelFor` rect as every menu) with a grid of everything held; tapping a cell equips it and closes the card.
- **Layout:** `Layout.screen` gains `hotbar`; only the plain tutorial card rises above the bar (`tutorialLift`), the carry card and the carrying tutorial keep their places. `LayoutAssert.hotbarChecks` runs in `standard` at every gate size.
