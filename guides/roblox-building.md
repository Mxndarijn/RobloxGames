# Roblox building: worktrees, Rojo files, done-criteria (2026-10-15)

How a bot builds a feature in `Mxndarijn/RobloxGames` (private monorepo: `games/<name>/`, `shared/`). Release steps after "done": [roblox-release-process.md](roblox-release-process.md). Toolchain install: [roblox-toolchain-linux.md](roblox-toolchain-linux.md).

## 1. One git worktree per agent

Several bots work at once. Never switch or edit another bot's checkout; each agent gets its own worktree and branch.

```sh
cd /workspace/roblox/RobloxGames
git fetch origin
git worktree add ../wt-<bot>-<topic> -b <bot>/<topic> origin/main
cd ../wt-<bot>-<topic>/games/steal-a-slime
rokit install                      # tools pinned in rokit.toml
# ... work, commit only your own files by path (never git add -A) ...
git worktree remove ../wt-<bot>-<topic>   # when the PR is merged
```

- Commit with the bot identity, push the branch, open a PR. Never push to main, never merge (Merijn merges).
- Read `games/<game>/CLAUDE.md` and `CONTRACT.md` first: folder owners, DataStore rule, contract-first changes.

## 2. Rojo-as-files

The repo is the source of truth; Studio is not. Everything that ships is a file Rojo maps (`default.project.json`):

- Code: `src/server`, `src/shared`, `src/ui`, `src/visuals` (`.luau`).
- World: `world/*.rbxmx` (generated by `lune run scripts/gen-world`, committed). `world/` is the only map source.
- Build outputs are git-ignored: `build.rbxlx`, `*.rbxl`, `src/visuals/static/*.rbxm`.
- Shared modules use the dual require (`if script then require(script.Parent.X) else require("./X")`) so Lune can test them.
- Never edit the place in Studio and publish from there as the normal path; Studio changes are lost on the next Rojo build.

## 3. Done = Lune + cloud + rhr all pass

A branch is done only when all three pass on the exact build you will ship.

**Lune / local** (from `games/<game>/`):

```sh
rojo build -o build.rbxlx
lune run tests                                  # unit + LiveBoot + RequirePaths + Members
selene src tests && stylua --check src tests
lune run scripts/check-place.luau build.rbxlx   # no DataStoreMode, void-safety
scripts/typecheck.sh
lune run tools/livetest/session build.rbxlx     # local stand-in player session (memory store)
```

**Cloud** (Saved version N, never live; see [roblox-cloud-server-test.md](roblox-cloud-server-test.md)):

```sh
python3 /workspace/roblox/live-testing/ci/run.py --version N --out /tmp/run-vN-$$.json
python3 /workspace/roblox/live-testing/ci/run.py tools/livetest/cloud/session.luau --version N --out /tmp/session-vN-$$.json
```

**rhr** (static UI layout, `roblox-headless-renderer==1.0.0rc1`, wrapper `~/.local/bin/rhr`):

```sh
rhr check build.rbxlx --devices all --out rhr-check.json
```

Note: code-built UI (SlimeUI) needs `*.story.luau` files, otherwise rhr reports "nothing checked", which is not a pass. Details: [roblox-automated-tests.md](roblox-automated-tests.md).

Put the commands you ran and their results (PASS lines, result paths) in the PR body.
